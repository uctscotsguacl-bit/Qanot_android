# QANOT backend

Bu backend boshlang'ich skelet. `/health` va `/operators` ishlaydi; `/tariffs` hozircha tasdiqlangan ma'lumot yo'qligini bildiradi. Balans, SMS va to'lov endpointlari rasmiy API adapterlari sozlanmaguncha 503 qaytaradi.

Ishga tushirish uchun yuqoridagi `../README_UZ.md` ko'rsatmalariga qarang. Ishlab chiqarishga chiqarishdan oldin foydalanuvchi autentifikatsiyasi, ma'lumotlar bazasi, HTTPS, monitoring, rate limit va provayderlarning imzo/callback tekshiruvlari majburiy.
